{% comment %} Unified Section Dispatcher (all locales) Renders a single resume section based on the 'section_name' parameter, replacing the separate resume-section-en.html / resume-section-ar.html per-language dispatchers. Usage: {% include resume-section.html section_name="experience" %} Dispatcher Architecture: - Iterated over by the active resume layout, looping through `site.resume_section_order`. - Dual-Condition Gate: Each section is evaluated against `include.section_name == ""` and its configuration flag `site.resume_section.` in `_config.yml`. - Data Source: Binds to `resume_data.
` resolved dynamically by the parent layout. - Locale Resolution: Resolves `lang`/`locale` the same way every other template does (page.lang, falling back to site.default_lang), and reads section headers from `locale.ui.section_titles`. - Dates: Uses `_includes/date-formatter.html` for every date interval. A blank/omitted `enddate` is passed through as "Present" (matched by every locale's `present_values`), so ongoing roles render the locale's present-tense string automatically. - RTL Bidi Protection: When `locale.direction == 'rtl'`, wraps URLs and credential IDs in `dir="ltr"` so Latin punctuation and alphanumeric IDs aren't scrambled by the bidi algorithm. No-op for LTR locales. - Recognitions: Accepts only the plural `site.resume_section.recognitions` flag; the legacy singular `site.resume_section.recognition` fallback is dropped (Task 3.4 confirms no references remain). - Microdata: Incorporates Schema.org semantic tags (Organization, CollegeOrUniversity, CreativeWork). - Print Media: Hyperlinks include print-only text fallbacks to ensure URLs remain legible on physical paper or exported PDFs. {% endcomment %} {%- assign lang = include.lang | default: page.lang | default: site.default_lang | default: 'en' -%} {%- assign locale = site.data.locales[lang] | default: site.data.locales[site.default_lang] -%} {%- assign rtl = false -%} {%- if locale.direction == 'rtl' -%} {%- assign rtl = true -%} {%- endif -%} {%- comment -%} Section: Experience - Data: `resume_data.experience` filtered by `active: true`. - Grouping: Groups multiple sequential roles under the same organization via `group_by: "company"`. - Sorting: Sorts positions chronologically by `startdate` in reverse order (newest first). - Formatting: Dynamically displays position, dates, and location with bullet separators (`•`) only between non-empty fields. - Durations vs Date Ranges: Renders explicit `durations` array if present (pre-formatted, not passed through date-formatter.html), otherwise formats startdate to enddate/Present. - Microdata: Schema.org `Organization` with `worksFor` itemprop. {%- endcomment -%} {% if include.section_name == "experience" and site.resume_section.experience %}
