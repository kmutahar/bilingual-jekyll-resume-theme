# Switch resume versions

*Audience: site owners*

Load a different set of resume data (for example a dated or role-specific version) for a language.

1. Point `data_path` at a dotted path. `languages.en.data_path: "2025-06.PM"` loads `_data/2025-06/PM/*.yml`.
2. To see how the path is resolved, read [layouts reference](../reference/layouts.md).
